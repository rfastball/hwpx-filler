# U5 실사용 피드백 라운드 — 간소화 판정 기록

2026-09-01. 사용자 실사용 피드백 17항의 트리아지·판정과 착지 기록이다. 라운드의 주제는
**표면 감량**이다: 같은 사실이 두 자리에 서는 중복 발화, 행동을 바꾸지 않는 상수 알림,
durable 결속 위에서 거짓이 된 안내, stale 어휘를 걷었다. 착지는 PR #963·#964·#966·#967·
#968·#969 여섯 슬라이스이고, 회수 이슈는 #965(zip 길이 flake)·#970(quickstart 캡처 재촬영)다.

원칙의 갱신은 없다 — 이 라운드는 「조용히 틀리지 않는다」의 **반대 방향 절제**를 명문화한다:
경보·고지는 행동을 바꾸는 사실에만 선다. 상수인 사실(첫 실행), 이미 다른 자리가 말한 사실
(빈 값 요약·실행 상태), 존재할 수 없는 동선(연결 0건 데이터의 「문서 작업에서 고르기」)은
말하지 않는 쪽이 경보를 지킨다 — 거짓·중복 문안은 경보를 싸구려로 만든다.

## 3. 착지한 판정 — 전역 설정 (#967 · #968)

- **설정 모달 신설**(사용자 확정: 드롭다운이 아니라 모달): 우상단 순환 토글 둘(◐·A)을 걷고
  ⚙ 하나 → `#settingsModal`. 순환 버튼은 지금 무엇이고 무엇을 고를 수 있는지를 누르기 전에는
  말하지 않는다 — 값 선택은 3값 세그먼트가 진다. 값 판정·영속은 종전 `preferences.ts` →
  브리지 경로 그대로(링 구조 불변).
- **저장 폴더 전역화**(사용자 확정: 세션별 지정 폐지): 저장 폴더는 작업의 속성이 아니라 앱의
  설정이다. 도출은 「①설정한 전역 저장 폴더(존재 확인 통과분) ②템플릿 옆 Results」 둘로
  접혔고(`SOURCE_EXPLICIT` 퇴역), 고르는 자리는 설정 모달의 저장 폴더 행 하나다. 값 가시성은
  「생성 예정 문서」의 출처 병기 줄이 지고, 하향 notice 는 존치(조용한 하향 금지).
  `REVIEW_DELIVERY` blocker 의 복구 동사 좌표는 `#settingsPickFolder` 로 이사했고 화면 쪽
  착지는 `#jobOpenFolderSettings`(문이지 복구 동사가 아니다 — 표에 실리지 않는다).
  설정 키 `last_output_directory` 는 이름 유지·의미 승격(마이그레이션 불요, U3-06 #879 승계).

## 4. 아직 서지 않은 것

- quickstart-101 캡처 2장(그림 8·`09-preflight-check.png`)의 픽셀이 걷힌 표면을 보여준다 —
  재촬영은 실습 홈에 쓰기가 있어 사용자 확인 후(#970).
- live101 「전체 선택」 착지의 zip 길이 경보 flake — 발원 가설까지 짚어 #965 로 회수.

## 5. 검증

- 슬라이스마다 `.\test.ps1` 전체(마지막 슬라이스 기준 4908 passed·커버리지 95%)와
  `--selftest` 실주행. DOM 좌표를 옮긴 슬라이스(#963·#968·#969)는 selftest 프로브·live101
  대본을 **같은 변경에** 담았다(#932 B4 규율).
- 문안·존 퇴역은 음성 단언으로 승계했다: 첫 실행 무고지 대기(live101 S5a), `#jobMirrorLine`
  부재 + 배너가 preflight 를 따르는 양성(`mirror_follows_preflight`), `restate_gone`.
- 저장 폴더 전역화는 실앱 양성 증거를 새로 세웠다: 「작업 선택 전에도 전역 폴더가 선다」
  (live101), 미선택 지정 유효·착석이 덮지 않음·양 축 동일 도출(계약 테스트).
- 설정 모달 프로브(`shell_settings`)는 기존 full 모드 창에 단계를 얹었다 — 새 콜드 부팅 0.
  selftest responsibility 3자리 동기(build.ps1·schema.js·runtime_artifact)는 #967 에서 43 으로
  한 번 움직였고 `uv run ruff check packaging` 으로 확인했다.

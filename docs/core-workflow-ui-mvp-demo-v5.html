    이 데이터 고정

    작업의 기본 데이터를 사용할까요?

    기본 데이터 참조는 조준 힌트입니다. 사용자 확인 없이 현재 데이터를 바꾸지 않습니다.

    시안 계약

    데이터 선택 확장 계약

    현재 데이터의 정체성

    Excel은 파일과 선택 시트, CSV는 파일이며 header row는 선택적인 후속 속성입니다.

    영속되는 것

    마지막으로 성공적으로 물린 참조, 선택 시트, 사용자가 고정한 데이터 참조와 시안용 문서 즐겨찾기만 localStorage에 저장합니다.

    영속되지 않는 것

    레코드 내용, 선택, 검색·필터, 실행 override, 검증, 미리보기·승인, 작업대 복사 상태와 실행 결과는 저장하지 않습니다.

    실행 데이터와 범위

    원본은 새 데이터 마운트 때 읽습니다. 이후 미리보기·HWPX·TXT는 화면에 적재된 같은 스냅샷과 전체 표시순서 기반 선택을 사용합니다.

    백엔드 경계

    Dataset Pool 참조 저장소, active/archived와 다중 시트 모호성 판정을 재사용합니다. 기본 선택 없음, ordered record indices 전달, snapshot-local identity와 원자 전환의 실제 제품 배선은 후속 구현이 필요합니다.

    현재 데이터 문서 탐색

    메인에는 사용 가능한 문서를 최대 5개만 보여주고, 전체 탐색에서는 연결 복구·기본 데이터 전환·새 작업 identity를 원인별로 분기합니다.

    구현하지 않는 것

    ERP 파일 이력, 데이터 카탈로그, 파일 버전 관리, 레코드 저장, 유사 스키마 자동 식별, 완전한 신규 작업 마법사는 포함하지 않습니다.

    현재 변경을 먼저 정리하세요

    기본 규칙으로 저장할까요?

    원본 파일에서 수정

    현재 선택과 실행 문맥은 유지됩니다. 이 시안은 원본 파일을 직접 바꾸지 않습니다. 외부에서 ‘성명’ 열을 복구한 뒤 다시 분석해야 하며, 지금 상태를 준비 완료로 바꾸지 않습니다.

    이 템플릿으로 새 문서 작업 만들기

    새 identity를 만든 뒤 현재 레코드 선택을 유지하고 검증합니다. 출발점 작업의 Binding은 변경하지 않습니다.

    기본 규칙으로 저장

    이번 세션에서 바꾼 항목만 새 Binding revision에 저장합니다.

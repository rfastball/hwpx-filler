# 지원 경계와 동결 기능

코드·테스트가 남아 있어도 제품 화면에 제공되는 기능이라는 뜻은 아니다.
이 문서는 비노출·비출하 경계를 소유한다. 착수 여부와 실행 상태는 GitHub 이슈에서 관리한다.

| 범위 | 현재 상태 | 유지하는 것 | 다시 노출하기 위한 조건 |
|---|---|---|---|
| 작업·템플릿 태그와 그룹 | 웹 UI에 노출하지 않음 | 모델·판정·기존 영속 | 수요 확인 후 투영·동사·게이트·실주행을 함께 복구 |
| 온보딩 튜토리얼 | 웹 진입점·마운트 없음; 배포 자산 비동봉 | 상태 모델·컨트롤러·설정·예제 자산·부품 | 현재 동선에 맞는 교육 설계와 설치·제거·실주행·패키징 계약 재검증 |
| 나라장터 API 데이터 소스 | 웹 UI에 노출하지 않음 | 어댑터·CLI 접합부 | 실제 운영 환경·인증·응답 계약과 사용자 수요 확인 |

온보딩이 구현됐다는 사실을 배포본에 튜토리얼이 들어 있다는 문장으로 바꾸지 않는다.
[packaging/verify_specs.py](../packaging/verify_specs.py)는 동결 자산의 비동봉을 검사한다.
[examples/onboarding](../examples/onboarding)은 유지하는 자산이며,
[quickstart-101](../examples/quickstart-101/README.md)은 저장소의 사용 실습이다.

기존 데이터 풀의 나라장터 항목은 숨기지 않고 미지원 사유를 알린다. 테스트는 서비스 키나
실 API 대신 fixture를 사용한다. 로컬 SQLite의 **계약 목록(pclm)**은 이 동결 대상이 아니다.
계약 목록 등록에서 제공할 수 있는 면은 `PCLM_DOC_VIEWS`와 해당 제품 게이트가 소유한다.

## 비목표

임의 조건식에 의한 자동 섹션 조립, 문서 수준 서식 조립, 여러 레코드를 한 문서의 반복
섹션으로 합치는 기능을 현재 지원한다고 설명하지 않는다. 작성자가 선언한 항목·선택을
사용자가 고르는 구성 기능과 이러한 자동 조립은 다른 범위다.

조판 수준 HWPX→PDF 내보내기를 제공하지 않는다. 산출물 구조 관찰은 PDF 변환이나
한글 조판 엔진이 아니다. 장기 검토 방향은 [로드맵](ROADMAP.md)을 따른다.

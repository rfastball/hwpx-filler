# 화면 규칙

<a id="ui-terms"></a>
## 용어·빈 값·단위

같은 개념은 버튼·오류·모달·로그·배지·파일 대화상자에서 같은 이름으로 말한다.
문안 정리만을 위해 Python/JSON 식별자나 문서에 남는 데이터 표식을 바꾸지 않는다.

| 개념 | 사용자에게 쓰는 말 |
|---|---|
| 제품 / `job` / `library` | 문서나르미 / 문서 만들기 / 문서 작업 |
| 매핑 원천 열 / 소스 종류 | 데이터 열 / 데이터 소스; '소스' 단독으로 열을 지칭하지 않음 |
| 저장 데이터 참조 / 통합문서 표 | 등록 데이터 / 시트; 구현의 '풀'은 노출하지 않음 |
| pclm SQLite 입력 | 계약 목록; 내부 프로젝트·뷰 식별자는 노출하지 않음 |
| 평문 토큰의 누름틀 전환 | 누름틀 변환 |
| 값 유형 | 텍스트 / 날짜 / 금액 / 고정값 / 오늘 날짜 |
| 날짜 표시형 | 시각 / 날짜+시각 등 표시형 명칭 |
| `Slot` / `Option` | 항목 / 선택 |
| 원본 조치가 남음 / 조치 후 결과 | 템플릿 조치 필요 / 템플릿 변경사항 |
| 값 없음 / 의도적 미채움 | 빈 값 / 비움 확정, 선택지의 `(비움)` |
| 데이터 열 없음 / 연결 제안 없음 | 항목 없음 / 후보 없음 |

`{{#항목 <id> <라벨>}}`·`{{/항목}}`, `{{#선택 <id> <라벨>}}`·`{{/선택}}`은 저작 문법이며
데이터 열 용어와 다르다. 정확한 UI 문자열은 생산자·테스트가 소유하고 폐기 화면명을 되살리지 않는다.

본문 `MISSING_MARKER`와 미리보기 `〈빈 값〉`은 설명 문장이 아닌 데이터 표식이다.
연결 표는 생성 표식을 그대로 사용하며 표식의 '미입력'을 웹에서 '빈 값'으로 재조립하지 않는다.
사용자 설명에는 폐기한 '미입력'을 새로 추가하지 않는다.

위치는 `행`·`열`, 필드·파일·토큰은 `개`, 작업·결과 목록은 `건`을 쓴다.
수치·진행은 `선택 3/120`처럼 라벨로 표시한다. 시트 크기 추정은 `약 N행×M열`로
근사임을 밝히고 실제 로드 행 수와 혼동하지 않는다. 공유 파일 필터·작업 방식 라벨·식별 요약은
기존 생산자를 재사용한다. 폼은 React/CSS 라벨·필드 시작선을 맞춘다. Qt 레이아웃을 전제하지 않는다.

## 문안과 검수

문안은 문제와 다음 행동을 말한다. 정상 경로는 기본 무음이다. 화면이 이미 보여 주는 결과,
설계 이유, 하지 않은 일의 나열을 낭독하지 않는다. 실패·불확실성·손실은 숨기지 않는다.

| 문형 | 예산과 형식 |
|---|---|
| 버튼·메뉴 | 행동이 분명한 명사구·동사구 |
| 상시 힌트·부제 | 기본 0; 빈 상태에서 다음 행동이 필요하면 한 문장 |
| placeholder / 툴팁 | 입력 예·이름 한 구 / 한 문장 `이름: 설명` |
| 상태·수치 | 라벨; 정상 완료 낭독 없음 |
| 오류 | 최대 두 문장: 문제, 조치 |
| 파괴 확인 | 제목=행동, 본문=결과·손실 집합, 확인 버튼=그 행동 |

명령형은 `~하세요`, 취소는 `취소`, 파괴 버튼은 `삭제`·`덮어쓰고 생성`처럼 구체적인 동사다.
파괴 확인의 기본 포커스는 취소다. 손실은 `사라지는 것: 선택 3행 · 필터 2조건`처럼 쓰고
'계속하시겠습니까?'만으로 실제 손실을 숨기지 않는다.

문장 안의 긴 대시와 낫표는 마침표·쉼표·작은따옴표로 바꾼다. 테이블의 독립 빈 칸 표식은
문장이 아니므로 예외다. '결속하다·물리다·겨누다'는 사용자에게 '연결하다'로 풀어 쓴다.
미입력·빈칸·미매칭을 설명에서 혼용하지 않는다. 데이터 표식은 위 용어 절의 예외를 따른다.

`연결된 파일을 찾을 수 없습니다. 데이터 파일을 다시 선택하세요.`처럼 문제와 조치를 나눈다.
시트 선택 이유를 설명하되 '조용히 첫 시트를 쓰지 않습니다' 같은 설계 원칙 낭독은 붙이지 않는다.
이 예시가 실제 문자열의 두 번째 정본은 아니다. 주석·docstring은 사용자 문안 규칙 밖이다.
문안 정리로 JSON 키·판정을 바꾸지 않고 assertion·census를 같은 변경으로 갱신한다.

[ui-copy-census.toml](../tests/contracts/ui-copy-census.toml)은 문장 allowlist다.
[스캐너](../scripts/ui_copy_census.py)와 [검사](../tests/repo_contract/test_ui_copy_census.py)가
다중집합을 대조한다. 새 문장은 기본 0이며 필요한 전문·이유를 PR에 적고 등록한다.
열거 밖 문장은 추가하지 않는다. 지운 문장도 함께 제거한다.
`uv run python scripts/ui_copy_census.py --write`로 갱신한다.

'해야 …할 수 있습니다', 정상 완료의 '불러왔습니다·가져왔습니다·복원했습니다', 문장 뒤
수치 나열, '실제 …입니다', 현재 화면·모드의 낭독은 금지 패턴이다.
`legacy = true`는 기존 유예에만 쓰며 총수는 늘지 않는다. 새 문장을 면제하는 수단이 아니다.
실행 정의는 스캐너의 `NARRATION_PATTERNS`다.

## 시각·배치·접근성

데이터 표와 연결 확인을 우선하는 한국어 데스크톱 도구다. 콘텐츠 사이트·장식적 대시보드를
그대로 옮기지 않는다. 무채색 표면·얇은 경계로 구획을 나누고 액센트는 동작·활성·포커스에
절제한다. 미확인·누락·선택은 의미색과 라벨·형태·접근 가능한 이름을 함께 쓴다.

동급 구획의 밀도·시작선을 맞춘다. 제목·조작부와 중복되는 부제보다 빈 상태의 다음 행동과
실패 복구를 우선한다. 색·여백·모서리·타이포·모션·층의 수치는
[design_tokens.json](../src/hwpxfiller/viewmodel/design_tokens.json) →
[생성기](../scripts/gen_design_tokens.py) → [tokens.css](../frontend/css/tokens.css)가 소유한다.
값을 이 문서에 복제하지 않는다. 컴포넌트는 제품 CSS·React와
[갤러리](reference/ui-gallery.html), vendor 경계는 [아키텍처](architecture.md)가 소유한다.

저작 작업대는 문서 탭·구조와 필드 목록·편집면·속성·시험 결과를 구별한다. 의미 요소는 색뿐
아니라 이름과 경계선으로 표시하며 문서 모드는 표시만 걷는다. 범위 확장·삭제·이름 변경은 적용
전에 실제 포함 내용과 연결 영향을 보여 준다. 전체 필드 이름 변경과 개별 사용 위치 변경을 섞지 않는다.
단추는 역할이 곧 모양이다 — 구획마다 하나의 주 행동(채움), 보조(테두리), 물러선 행동(테두리 없음), 파괴(위험 채움),
그림 단추(이름은 접근 이름·툴팁). 원문으로 옮겨 가는 목록·트리 행, 브레드크럼, 메뉴 항목은 단추 모양을 쓰지 않는다.
상태 막대의 누를 수 있는 표지(문제 수·시험 상태)는 그 독 탭으로 가는 글 링크 모양이며, 해당 없는 상태는 상태 막대에 세우지 않는다.
머리 띠·도구 막대는 편집기처럼 명령을 테두리 없이 두고 띠마다 실행 행동 하나만 테두리·채움으로 세우며, 파일 동사는 「파일」 메뉴에 둔다.
위치 줄 끝의 메모 칸은 지금 자리에 대한 Python 사유 한 줄이며(되는 이름 변경이 없는 F2는 패널 대신 이 칸에 사유를 세운다)
다음 캐럿 이동이나 Escape에서 걷힌다. 도구 막대의 만들기 단추는 판정이 불가이면 흐린 `aria-disabled` 단추로 초점과
방향키 차례를 받고, 누르면 명령 대신 이 칸에 그 사유를 세운다. 판정 전에는 사유 없이 비활성이다.
구조 패널의 빈 상태 문장은 첫 행동인 필드 만들기 하나이며 필드도 항목도 없을 때만 선다. 처음 여는 문서에 첫 안내 알림은 없다.
문서 탭·도구 막대·구조 목록·메뉴는 WAI-ARIA APG 키보드 모델을 따라 한 번의 Tab으로 들어와 방향키로
옮긴다. 명령의 불가 항목은 표면마다 달리 싣는다. 자동 표면인 문맥 메뉴는 되는 명령과 대안만 싣는다. 판정 전에는
사유 없이 흐린 항목을, 되는 것이 없으면 팔레트를 여는 「명령」 한 줄과 그 위에 모든 불가 명령이 같이 가진 사유 한 줄을
싣는다. 유일한 예외로 편집면에서 연 문맥 메뉴는 「필드로 만들기」를 늘 첫 항목으로 싣고, 불가이면 흐리게 두고 Python
사유를 그 항목의 설명 줄로 보인다. 명시 표면인 명령 팔레트·속성 명령 선택·도구 막대는 불가 명령을 흐리게 두고 Python 사유를 보이며,
누른 키(F2)는 그 자리에서 사유를 보인다. 문맥 메뉴에서 불가 항목이 초점을 받아 사유를 읽히던 이전 규칙은 이것으로
대신한다. 명령 팔레트(Ctrl+Shift+P, 「더보기」 메뉴에 키 표기)는 머리 띠 아래의 비모달 오버레이(APG combobox·listbox)다. 이름 부분 일치로 거르고,
되는 명령과 셸 동작을 단축키 표기와 함께 먼저, 불가 명령은 같은 사유끼리 한 번 묶어 뒤에 둔다. ↑↓는 흐린 항목에도
서고, Enter는 되는 항목만 실행하며, Escape는 팔레트만 닫고 연 자리로 돌린다.
초점은 사용자가 패널을 열 때만 옮기고 닫으면 연 자리(속성은 선택 자리)로 돌린다. 화면 읽기 알림은 단일 live
region이 상태 전이 때만 내며, 오류는 닫거나 같은 종류의 작업이 성공할 때까지 남는다. 오류 띠는 호출
실패만 보이고, 시험 입력 검증 실패는 시험 패널의 상태로만 보인다. 시험 입력의 공백은 결과 시험 탭 배지와
입력칸 표지로 센다.

눌림 효과가 표 정렬을 깨뜨리지 않아야 한다. reduced-motion 두 경로의
[실렌더 기하](../tests/test_web_press_geometry.py)를 검사한다. 저작 작업대의 열 폭·좁은 폭 시트·
강제 색상 표지는 창 폭과 글자 배율별 [배치 실렌더](../tests/test_web_authoring_layout.py)가 잰다. 포커스·캐럿·스크롤·IME 연속성,
모달 포커스 포획·복귀와 비활성 사유를 지킨다. 라이트·다크 모두
[대비 검사](../tests/repo_contract/test_contrast_wcag.py)와 실제 렌더를 통과해야 한다.
대비 하한·대상 쌍은 테스트가 소유한다. [실앱 검사](../tests/test_web_selftest_gate.py)는
실제 결과를 검증하며 정적 CSS 존재나 테스트 통과를 접근성 인증으로 설명하지 않는다.

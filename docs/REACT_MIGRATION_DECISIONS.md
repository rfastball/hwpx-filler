# React 전환 목표 아키텍처 ADR

> **문서 상태:** 현재 정본
> **권위 범위:** React/TypeScript 전환의 목표 구조, 계층별 권위, 장기 불변식, 비목표, 후속 소유처
> **후속 정본:** 없음
> **편집 정책:** R 단계 진행 중 계속 갱신. 뒤집힘은 새 ADR 항목이 소유한다

전환의 **헌장**이다. 무엇을 만들지가 아니라 **무엇이 무엇의 권위인가**를 고정한다. 단계 순서와
완주 판정은 #394 (R-00) 가 소유하고, 이 문서는 그 결정 원장 R-D01~R-D17 을 저장소가 읽을 수 있는
형태로 옮겨 각 항목의 **근거·거절 대안·후속 소유 단계**를 붙인다.

기준 실측 커밋: **`73473de`**. 이 문서가 인용하는 수치는 전부 그 커밋에서 잰 값이고, 출처를
함께 적는다. **수치는 낡는다** — 「오늘의 배치」 절은 목표 구조가 아니라 기준선이다.

## 추적성 계약

각 ADR 항목은 제목 바로 아래에 `**추적:**` 줄을 갖고, 그 줄이 이 항목이 승계하는 R-00 결정
번호를 적는다. **R-D01~R-D17 17개가 모두 어느 항목엔가 등장해야 한다** — 하나라도 주인이 없으면
`tests/test_react_migration_adr.py` 가 붉어진다. 역방향(항목이 없는 R-D 번호를 적는 것)도 막는다.

R-00 본문의 결정이 18번째로 늘면 그 게이트는 **초록인 채 새 항을 놓치지 않는다** — 상수 17 이
출처와 함께 못박혀 있어 시끄럽게 실패한다.

## ADR 항목

### ADR-01 — 렌더 모델을 전체 스냅샷+복원에서 React 재조정으로 뒤집는다

**추적:** R-D03

[웹 재렌더 보존](WEB_RENDER_PRESERVATION.md) 은 「전체 스냅샷 모델을 유지하고 … **부분 패치/vdom
으로 전환하지 않는다**」를 결정했다. React 전환은 이 결정을 정면으로 뒤집으므로, 전환의 첫 항목이
그 승계·폐기 사유를 소유한다.

**그 문서의 재고경계는 오늘도 참이다.** 「해로운 케이스는 아래 세 조건이 **동시에** 성립해야
한다」의 세 조건을 축자 인용하고 `73473de` 에서 각각을 판정한다:

| # | 재고경계 조건 (축자) | 오늘 | 근거 |
|---|---|---|---|
| 1 | 푸시가 `input`/`keyup`(글자 단위)에서 발생 — `change`/`blur`/`click` 아님 | **거짓** | 푸시는 여전히 이산 액션에서만 난다. R-D03 이 R1~R4 의 제품 의미 보존을 강제하므로 R 단계에서 참이 되지 않는다 |
| 2 | 포커스된 편집 노드가 `render()` 재구성 서브트리 **안**에 있음 | **참** | 재구성 서브트리 안에 포커스 가능한 컨트롤이 있다. 다만 그 문서 스스로 「모두 캐럿을 갖지 않거나 id 가 없다」고 적었다 |
| 3 | 재구성이 full `innerHTML`(노드 파괴) | **참** | 제품 `innerHTML =` **61**회(전체 69 − selftest 프로브 8), `insertAdjacentHTML` 0 |

「하나라도 거짓이면 복원으로 충분하다」 — 1이 거짓이므로 **오늘도 복원으로 충분하다.**

**그러므로 전환의 강제함수는 그 세 조건이 아니다.** 재고경계는 **렌더 정확성** 축에서 세워졌고,
전환은 **수명주기 소유권** 축에서 온다. 강제함수의 실측 형태:

- `addEventListener` **123** vs `removeEventListener` **12** — 비대칭 **111**. 해제 짝이 없다는
  것은 게으름이 아니라 **구조**다. 화면 셸에 언마운트 개념이 없어 짝을 놓을 자리 자체가 없다.
- `Bridge.onPush` 구독 지점 **6**곳에 대해 `frontend/js/bridge.js` 는 채널별 배열에 누적만 하고
  **구독 해제 API 가 없다**. 재-init 이 렌더를 2벌로 만드는 것을 각 화면이 `wired` 플래그로 막는다
  — 즉 수명주기를 화면마다 손으로 흉내 낸다.
- 가변 모듈 상태 **36**개가 **6**파일에 흩어져 있고 `MUTABLE_MODULE_STATE_BUDGET`
  (`tests/test_web_dom_contract.py:64`) 의 상한에 **정확히 붙어** 있다. 예산은 천장을 지키지
  소유자를 만들지 못한다.

이 셋 중 어느 것도 「재렌더가 상호작용을 깬다」가 아니다. 그래서 그 문서는 **폐기가 아니라 부분
대체**다 — 대체되는 것은 「부분 패치/vdom 으로 전환하지 않는다」 한 줄이고, 보존 책임·재고경계·
진단 증상·에스컬레이션 순서는 그대로 유효하다. 특히 재고경계의 「가장 뾰족한 트리거는 한글 IME」
는 #299 (린트메모장·CodeMirror) 가 라이브 편집면을 들여올 때 **다시 읽어야 할 문장**으로 살아
있다.

**그 문서의 예언은 절반만 참이었다.** 근거 4 「엑싯이 싸다」(`:68-71`) 는 부분 패치의 실비용을
`host.innerHTML = html` → `morph(host, html)` **커밋 한 줄 교체**로 추정하고 「게이트 단언은
패치에서도 참이라 **그대로 전이**된다. 락인 0.」이라 적었다.

- **참인 절반 — 성질을 겨눈 단언은 전이된다.** 「푸시 후 포커스·스크롤 생존」은 렌더러와 무관한
  사용자 관찰 가능 성질이라 selftest live 게이트가 그대로 들고 간다.
- **거짓인 절반 — 배선을 겨눈 단언은 후계가 필요하다.**
  `test_web_dom_contract.py:646` 은 「4개 화면 `render()` 가 `Preserve.around` 로 감싸져 있다」를
  단언한다. 그 파일의 docstring 이 스스로 밝히듯 이것은 **배선의 존재**를 보는 정적 가드다.
  React 에는 `Preserve.around` 도 화면별 `render()` 도 없으므로 이 단언은 전이되지 않고 **후계
  지정**이 필요하다. 후계의 소유는 [old→new 검증 책임 원장](react_verification_ledger.toml)
  (#403) 이다.
- **예언이 세지 않은 비용.** 「락인 0」은 `Preserve.around` 가 순수 봉투라는 사실에서 나왔고 그
  자체는 맞다. 하지만 위의 비대칭 111 과 구독 해제 부재는 봉투가 아니라 구조다. **락인이 아니라
  미청산 부채였다** — 부채는 삭제로 사라지지 않고 인수된다.

**거절한 대안**: (a) morphdom 커밋 교체 — 렌더 정확성만 고치고 수명주기 소유자를 만들지 못한다.
(b) 재고경계가 참이 될 때까지 유예 — 강제함수가 다른 축에 있으므로 영원히 오지 않는다.

### ADR-02 — Python 은 도메인·애플리케이션 권위, React 는 DOM·표현·수명주기 권위다

**추적:** R-D04

권위가 **겹치거나 공백인 상태를 허용하지 않는다.** 같은 상태를 두 곳이 판정하는 구조는 이
저장소가 반복해 만난 결함류이고(`CLAUDE.md` 「같은 상태를 두 곳이 판정하게 만들지 않는다」),
전환은 그 경계를 옮기지 않는다 — 링1 ViewModel 이 소유한 **판정·게이트·문안**은 React 로
내려오지 않는다.

React 가 인수하는 것: DOM, 표현, UI draft(확정 전 입력), UI 수명주기(마운트·언마운트·구독).
Python 에 남는 것: 사실, 거래 상태, 판정, 사용자 문안, 파일·OS 효과.

「UI draft」와 「제품 사실」의 경계는 R1 이 노드 단위로 분류한다 —
[소유권 인벤토리](react_ownership_inventory.toml) (#402).

### ADR-03 — 공개 제품 경계는 `window.__hwpx` 하나, selftest 는 `window.__hwpxTest` 하나다

**추적:** R-D05

Python 이 아는 웹 이름은 버전 있는 파사드 하나다. `73473de` 실측으로 제품 전역은 **정확히 2**개
(`window.__hwpx` 생산자 `frontend/src/bootstrap.js` 1곳 · `window.__hwpxTest` 생산자
`frontend/src/selftest/api.js` 1곳, `defineProperty` 조건부)이고, N-10 에서 종전 내부 전역 5개가
사라졌다. **전환은 이 수를 늘리지 않는다.**

`describe()` 가 반환하는 capability **순서가 계약**이다(`webapp/product_api.py`). React root 가
생기더라도 이 계약의 생산자는 하나로 남는다 — root 가 여럿이면 어느 root 가 파사드를 세우는지가
경합이 된다.

### ADR-04 — feature/component 는 전역을 직접 읽지 않는다. 브리지는 **객체째 주입**한다

**추적:** R-D05

컴포넌트는 `window.pywebview` 도 `window.__hwpx` 도 직접 조회하지 않고 typed bridge client 를
통한다. 오늘 프런트에서 `window.pywebview.api` 를 직접 조회하는 파일은 `frontend/js/bridge.js`
**하나**이고, 이 수도 늘지 않는다.

**장기 불변식 — 브리지는 객체째 주입한다.** 함수 하나씩 뽑아 넘기지 않는다. 오늘 `bridge.js` 와
푸시 포트가 지키는 규율이고, typed client·store 층이 생겨도 유지돼야 한다. 이유는 두 가지다:
① 개별 함수 주입은 **주입 지점마다 다른 부분집합**을 만들어 「이 컴포넌트가 무엇에 닿는가」를
호출부 전수조사로만 알 수 있게 한다. ② 테스트 대역이 객체 하나면 교체가 한 줄이고, 함수별이면
교체가 시그니처 수만큼 흩어져 **대역이 실물과 조용히 갈린다**.

R2 가 typed client 를 세울 때 이 불변식이 그 설계의 입력이다 — 그래서 도구를 고르기 **전에**
헌장에 박는다.

### ADR-05 — Python↔TypeScript 계약은 단일 정본에서 생성하거나 검증한다. drift 는 CI 에서 loud fail 한다

**추적:** R-D08

**같은 계약을 두 언어가 각각 손으로 유지하는 상태를 허용하지 않는다.** 정본 하나에서 생성하거나,
생성이 과하면 최소한 **양방향** drift gate 가 선다. 도구 선택은 R2 실측 뒤다(ADR-07).

`73473de` 의 실상은 「위반이 있다」가 아니라 **「각 언어가 자기 리터럴에 초록으로 고정돼 있고,
교차 언어 등가만 미검증」**이다. capability 목록 사본은 최소 여섯이고 오늘 여섯이 전부 일치하며,
그중 둘은 초록 단언이 지킨다. 따라서 R2 의 drift gate 는 **합성 fixture** 로 판별력을 세워야
한다 — 실재 위반 표본이 없으므로 「빨갛게 만들 수 있다」를 증명하지 않으면 첫 성립이 음성 대조
없는 초록이 된다.

무게이트 사본 2곳(`src/hwpxfiller/webapp/product_api.py` docstring · [UI 계약](UI_CONTRACT.md)
산문)의 위치는 #403 원장이 기록한다.

**오늘의 drift gate 는 단방향이다.** `tests/test_architecture.py:399` 는 `bridge.js` → UI 계약
방향만 본다. Python 공개 메서드가 늘어도 문서가 침묵하면 아무도 붉어지지 않고, 실물이
`WebFrontend.close_guard_state` 다 — JS 에서 도달 가능한데 `bridge.js` 에도 UI 계약 목록에도
없다. **양방향 강제의 소유는 #406 (R2-02)** 이고, `close_guard_state` **자체의 처분**은 #433
인계다.

### ADR-06 — 산출물 하나, UI 런타임 하나

**추적:** R-D06 · R-D07

정상 실행·selftest·PyInstaller·릴리스는 **한 clean 빌드의 동일 sealed 산출물**을 소비한다. React
root 는 **정확히 하나**이고 제품 화면은 하나의 컴포넌트 트리에서 난다.

단계 중 임시 legacy host 를 두더라도 **제거 책임과 종료 단계**를 함께 갖는다. 종료 단계가 없는
임시 host 는 임시가 아니다.

**identity 는 성질을 지키지 않는다.** sealed 산출물의 대조는 「같은 파일인가」를 답하지 「그 파일이
같은 일을 하는가」를 답하지 않는다 — 봉인 대조가 초록인 것은 전환이 옳다는 증거가 아니다. 성질은
selftest live 게이트가 진다.

### ADR-07 — router·전역 상태·CSS 격리·타입 생성 도구는 후결정한다

**추적:** R-D09

실제 문제와 경계가 확인되기 전에 채택하지 않는다. R2 가 실측 뒤 고른다.

이 항목은 **금지가 아니라 순서**다. 「지금 안 고른다」는 「영원히 안 쓴다」가 아니고, 고를 때는
그 도구가 **어떤 실측된 문제**를 푸는지를 근거로 남긴다.

### ADR-08 — #299·#300·#360 은 완료 조건이 아니라 후속 소비자다

**추적:** R-D10

기술 스파이크가 필요해도 **제품 경로에 기능을 착지하지 않는다.** 외부 엔진(CodeMirror·rhwp)은
React 가 mount/update/dispose 를 소유하는 **adapter 안**에 머문다 — 엔진이 React 밖에서 DOM 을
직접 들면 ADR-02 의 수명주기 권위가 깨진다.

### ADR-09 — 단계 실행 규율: 진입 게이트·단계별 재설계·master 불변식·독립 판정

**추적:** R-D01 · R-D02 · R-D11 · R-D12 · R-D13

- **실행 권위**는 #394 다. 이 ADR 은 그 결정의 저장소 표현이지 상위 권위가 아니다.
- **진입 게이트**: R1 구현은 #384 N-99 가 병합 master SHA 에서 통과한 뒤에만 열린다.
- **단계별 재설계**: 하위 이슈 본문은 경계만 등록하고, 세부 DAG·write set·검증 패킷은 **각 단계
  진입 master 를 다시 측정한 뒤** 확정한다. 인용이 아니라 재실측이다 — 수치는 낡는다.
- **master 불변식**: 각 병합 시점의 master 는 실행·검증·revert 가능해야 한다. **여러 미완성 PR 을
  동시에 합쳐야 정상화되는 방식은 금지한다.** 실무 귀결: 문서 지도가 「아직 없는 파일」을 가리키는
  중간 master 가 생기더라도, 그 지도를 읽는 게이트는 **존재를 단언하지 않는다**(존재 단언은 각
  산출물 자신의 게이트가 진다).
- **독립 판정**: 각 단계의 설계자·구현자·통합자와 `R*-99` 판정자는 역할과 컨텍스트를 분리한다.
  판정자는 write set ∅ 다 — **감사는 조치를 소유할 수 없다.** 감사가 찾은 결손의 보강은 반드시
  구현 슬라이스로 배정된다.

### ADR-10 — P 후속 권위 분류와 #433 인계

**추적:** R-D14 · R-D15 · R-D16

R 단계는 Python 의 도메인·애플리케이션 의미와 **내부 구조를 재설계하지 않는다.** 전환 과정에서
확인된 Python 잔존 권위·화면 결합·제품 계약 결합·host 경계와 legacy screen/action 표면은 P-00
#433 에 인계한다.

**R 은 P 의 해결안을 만들지 않는다.** R1 은 인계 후보와 현재 증거로 **기준선**을 만들고, R5 는
React 이관 뒤 실제 잔존 구조를 다시 계측해 최종 패킷을 닫으며, R5-99 는 그 완전성만 독립
판정한다.

분류 어휘는 아래 절이 소유한다.

### ADR-11 — legacy 표면은 확대하지 않는다

**추적:** R-D17

이관 대상 legacy screen/action 표면에는 **신규 제품 기능을 추가하지 않는다.** 불가피한 계약
확장은 #394 상향 대상이며 Python 내부 구조 재설계를 동반하지 않는다.

오늘의 표면 크기: 화면 **6**(`library`·`editor`·`job`·`workbench`·`pool`·`tpl`), (화면, 액션) 쌍
**119**. 이 수가 R 단계에서 **늘면** 이 항목 위반이다.

### ADR-12 — 오늘의 배치는 기준선이지 목표 구조가 아니다

**추적:** R-D11

ADR 은 목표 상태와 경계를 고정하되 **현재 파일 배치를 영구 구조로 박제하지 않는다.** 아래
「오늘의 배치」 절의 수치는 R5 가 delta 를 재기 위한 기준선이고, 그 자체가 지켜야 할 값이 아니다.

**선행 Vanilla 분할을 지시하지 않는다.** `app.js`·`job.js`·`editor.js` 를 React 이관 전에 먼저
쪼개는 것은 같은 코드를 두 번 옮기는 일이다. 구조 분할은 React 이관과 **한 번에** 한다.

## 권위 분류 어휘

React 가 인수하지 않는 상태·동사에 붙이는 분류다. #401 본문의 대문자 분류값을 **소문자로 승계**
하고, [소유권 인벤토리](react_ownership_inventory.toml) (#402) 가 이 철자를 그대로 enum 으로
쓴다. 두 문서의 철자가 갈리면 #402 게이트가 붉어진다.

| 값 | 의미 |
|---|---|
| `react` | DOM·표현·UI draft·UI 수명주기 — React 가 인수한다 |
| `python_product` | React 가 인수하지 않고 Python 제품 권위에 남는 사실·거래 상태 |
| `host` | 창·WebView·운영체제 효과 |
| `retire` | React 전환과 함께 폐기 |
| `p_review_required` | Python 제품에 남지만 domain/application/host/adapter 내부 위치를 R 에서 결정할 수 없음 |

`p_review_required` 항목은 #433 인계 원장에 포함한다. **R1 은 이를 `DOMAIN`·`APPLICATION`·
`PORT`·특정 패키지나 클래스 형태로 세분하지 않는다** — 세분은 P 의 해결안이고 ADR-10 이 금지한다.

### 「직접 브리지」는 세 개의 다른 집합이다

「직접 브리지 21」이라는 표현이 저장소 안에서 **세 가지 다른 것**을 가리킨다. ADR 은 단일 수로
적지 않고 셋을 각각 이름으로 구분한다 — 하나의 수로 적으면 게이트가 세는 값과 갈린다.

| 집합 | 크기 | 정의 | 재계산 방법 |
|---|---:|---|---|
| **산문 정본 집합** | 21 | 사람이 읽는 [UI 계약](UI_CONTRACT.md) 「직접 브리지 경로」 열거 | 그 절의 backtick 식별자 중 소문자 snake_case |
| **Python 도달 집합** | 24 | `WebFrontend` 의 실제 공개 표면 (= 21 + `initial` + `dispatch` + `close_guard_state`) | 클래스 반사 |
| **게이트 대조 집합** | 23 | `test_architecture.py` 가 **실제로 대조하는** 집합 (= 21 + `selftest_claim` + `selftest_host_op`) | `bridge.js` 의 `api.<이름>` − {`initial`, `dispatch`} |

**게이트 대조 집합의 두 여분은 `WebFrontend` 메서드가 아니다** — `selftest_claim`·
`selftest_host_op` 는 `webapp/selftest_api.py` 소유다. **Python 도달 집합의 여분
`close_guard_state` 는 산문 정본에도 `bridge.js` 에도 없다** — ADR-05 가 말한 단방향 게이트의
실물이다.

`frontend/js/bridge.js` 머리말은 이 표면을 「23개(데이터·네이티브 21 + 창 닫기 확인 2)」로
분해하지만, 산문 정본 21 에 창 닫기 2가 **이미 포함**돼 있으므로 그 분해는 19+2 여야 한다.
**저장소 자신의 주석도 낡았다** — 이 절이 그 정정을 소유한다.

| router·전역 상태 라이브러리·CSS 격리 방식 | R2 이후, 실측 근거를 남기고 |

## 게이트

이 ADR 은 산문이지만 **다섯 술어가 기계로 지킨다** — `tests/test_react_migration_adr.py`.

1. R-D01~R-D17 **17개 전부**가 어느 항목엔가 `**추적:**` 으로 등장하고, 미지의 R-D 번호는 없다.
2. ADR 이 [웹 재렌더 보존](WEB_RENDER_PRESERVATION.md) 을 승계 대상으로 명시하고, **그 파일의
   머리말이 실제로** `부분 대체` + 후속 정본 = 이 파일이다. 두 파일을 함께 읽어 대조한다.
3. [문서 지도](README.md) 가 R1 3산출물 경로를 전부 언급하고, 웹 재렌더 보존 행의 상태가
   `부분 대체` 다. **파일 존재는 단언하지 않는다**(ADR-09 master 불변식).
4. 분류 어휘 5종이 **정확히 그 철자로** 정의돼 있다.
5. 「직접 브리지」 세 집합의 크기를 **저장소에서 재계산해** 이 문서의 기재와 대조한다. 정적 상수를
   믿지 않는다.

각 술어에는 합성 fixture 음성 대조 짝이 있다 — **빠뜨리면 붉어진다**를 먼저 증명한다.

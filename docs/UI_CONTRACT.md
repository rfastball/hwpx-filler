## 변경 단위

화면의 추가·삭제·개명은 컨트롤러, action registry, 프런트 라우팅, 화면 루트,
blocker 복구 동사, selftest·실주행 대본을 함께 변경한다. `pool`·`tpl`처럼 화면의 일부가
구독하는 채널을 최상위 화면과 혼동하지 않는다. 내부에 구현이 있다는 이유만으로 사용자
기능이라고 설명하지 않는다. [동결 범위](FEATURE_SCOPE.md)를 먼저 확인한다.

직접 네이티브 호출은 dispatch registry의 검증 범위 밖이다. 메서드 본문이 입력을 검증하고,
브리지 계약 생성물과 독립 오라클이 공개 경계를 대조한다. 직접 메서드 목록은 위 생성 참조가
소유한다. 여기에 같은 목록을 손으로 복제하지 않는다.

문서 수정 절차와 CI 검사는 [문서 유지 규칙](MAINTENANCE.md)을 따른다.

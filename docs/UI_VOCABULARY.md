# UI 용어와 단위

사용자에게 같은 개념은 한 이름으로 말한다. 버튼뿐 아니라 오류·모달 제목·로그·배지·파일
대화상자에도 적용한다. 내부 Python/JSON 식별자나 문서 안에 남기는 데이터 표식의 이름을
문안 정리만을 위해 바꾸지는 않는다. 문형·길이는 [문안 가이드](COPY_STYLE_GUIDE.md)가 소유한다.

## 현재 용어

| 개념 | 사용자에게 쓰는 말 |
|---|---|
| 제품 | 문서나르미 |
| 생성 화면 `job` | 문서 만들기 |
| 저장 작업의 라이브러리 `library` | 문서 작업 |
| 매핑의 원천 열 | 데이터 열 |
| 데이터 소스 종류 | 데이터 소스; 「소스」 단독으로 열을 지칭하지 않음 |
| 저장한 데이터 참조 | 등록 데이터; 구현의 「풀」은 노출하지 않음 |
| 통합문서의 표 한 장 | 시트 |
| pclm SQLite 입력 | 계약 목록; 내부 프로젝트명·뷰 식별자는 노출하지 않음 |
| 평문 토큰을 누름틀로 변환 | 누름틀 변환 |
| 값 유형 | 텍스트 / 날짜 / 금액 / 고정값 / 오늘 날짜 |
| 날짜 표시형 | 시각 / 날짜+시각 등 표시형 명칭 |
| 템플릿 구간 `Slot` | 항목 |
| 구간 안의 갈래 `Option` | 선택 |
| 원본에 할 일이 남은 구획 | 템플릿 조치 필요 |
| 조치 후 결과를 설명하는 구획 | 템플릿 변경사항 |

구간 표기의 `{{#항목 <id> <라벨>}}`·`{{/항목}}` 및
`{{#선택 <id> <라벨>}}`·`{{/선택}}`은 템플릿 작성자가 쓰는 문법이다.
데이터 열을 뜻하는 말과 섞지 않는다. UI 라벨의 정확한 문자열은 해당 생산자와 테스트가
소유한다. 폐기한 화면의 이름을 예제 문안으로 되살리지 않는다.

## 비어 있음의 구분

| 의미 | 문안 |
|---|---|
| 데이터에 값이 없음 | 빈 값 |
| 사람이 의도적으로 채우지 않음 | 비움 확정; 선택지의 `(비움)` |
| 데이터 열 자체가 없음 | 항목 없음 |
| 자동 연결 제안이 없음 | 후보 없음 |

누락된 값을 실제 본문에 남기는 `MISSING_MARKER`와 미리보기의 `〈빈 값〉`은 일반 설명
문장이 아닌 **데이터 표식**이다. 연결 확인 표는 도메인의 생성 표식을 그대로 사용한다.
표식 안에 「미입력」이 있다는 이유로 표식을 「빈 값」으로 별도 재조립하지 않는다.
반대로 사용자 설명 문장에는 폐기한 「미입력」 용어를 새로 추가하지 않는다.

## 단위와 배치

행 위치를 가리킬 때는 `행`, 열은 `열`, 필드·파일·토큰 등 이산 대상은 `개`를 쓴다.
작업·결과 목록의 건수는 `건`을 쓴다. 개수와 진행 비율은 `선택 3/120`처럼 라벨로
표시하고 정상 완료 문장으로 감싸지 않는다. 시트의 물리 크기 추정은 `약 N행×M열`처럼
근사치임을 드러내며 실제 로드한 행 수와 혼동하지 않는다.

폼은 현재 React/CSS의 라벨·필드 시작선을 맞춘다. Qt의 `QGridLayout`, `QGroupBox`,
위젯 signal을 현재 레이아웃 계약으로 사용하지 않는다.

## 검수

공유 파일 필터·작업 방식 라벨·식별 요약은 기존 생산자를 재사용한다. 화면별로 다시
번역하거나 조립하지 않는다. 새 용어를 정할 때 현재 문안 생산자와
[문안 census](ui_copy_census.toml)를 대조하고, 관련 행동 테스트도 함께 수정한다.

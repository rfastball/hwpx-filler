    이 데이터 고정

    작업의 기본 데이터를 사용할까요?

    기본 데이터 참조는 조준 힌트입니다. 사용자 확인 없이 현재 데이터를 바꾸지 않습니다.

    시안 계약

    작업 방식과 문서 작업 라이브러리 계약

    시스템 작업 방식

    템플릿 경로가 .hwpx면 HWPX 문서 생성, .txt면 온나라 기안 검토·복사입니다. 그 밖의 확장자는 추측하지 않고 ‘지원 작업 방식 확인 필요’로 두며 실행 후보에서 제외합니다.

    분류축의 역할

    사용자 그룹은 전역 목록의 공간 구조, 작업 방식은 실행·편집·결과를 결정하는 시스템 축, 태그는 다중 facet입니다. 문서 만들기와 현재 데이터 탐색은 작업 방식으로, 문서 작업의 모든 작업 보기는 사용자 그룹으로 구획합니다.

    최근 사용

    HWPX는 한 건 이상 생성에 성공하면, 온나라 기안은 한 건이라도 복사 완료 사건이 생기면 최근 사용으로 기록합니다. 작업대 진입만으로는 기록하지 않습니다. 이 시안의 복사 버튼은 실제 클립보드 호출이 아니라 mock 완료 사건입니다.

    템플릿 바꾸기

    다른 작업 방식의 템플릿은 조용히 적용하지도, 즉시 막지도 않습니다. 영향 안내 → 새 작업 또는 현재 작업 전환 → 연결 재검토 → 마지막 확인 → 원자적 저장 순서이며, 어느 단계에서 취소해도 기존 템플릿·연결·판본·실행 상태가 그대로입니다.

    현재 데이터의 정체성

    Excel은 파일과 선택 시트, CSV는 파일이며 header row는 선택적인 후속 속성입니다.

    영속되는 것

    마지막으로 성공적으로 물린 참조, 선택 시트, 사용자가 고정한 데이터 참조, 시안용 문서 즐겨찾기와 시안용 최근 사용 시각만 localStorage에 저장합니다. 즐겨찾기와 최근 사용의 제품 저장 소유자는 아직 확정된 백엔드 API가 아닙니다.

    영속되지 않는 것

    레코드 내용, 선택, 검색·필터, 실행 override, 검증, 미리보기·승인, 작업대 복사 상태와 실행 결과는 저장하지 않습니다.

    실행 데이터와 범위

    원본은 새 데이터 마운트 때 읽습니다. 이후 미리보기·HWPX·TXT는 화면에 적재된 같은 스냅샷과 전체 표시순서 기반 선택을 사용합니다.

    백엔드 경계

    Dataset Pool 참조 저장소, active/archived와 다중 시트 모호성 판정을 재사용합니다. 기본 선택 없음, ordered record indices 전달, snapshot-local identity와 원자 전환의 실제 제품 배선은 후속 구현이 필요합니다.

    현재 데이터 문서 탐색

    메인에는 사용 가능한 문서를 전체 합계 5개까지만 보여주고 작업 방식으로 구획합니다. 전체 탐색에서는 사용 가능·확인 필요 탭 안에서 다시 작업 방식으로 구획하며, 연결 복구·기본 데이터 전환·새 작업 identity·지원 범위를 원인별로 분기합니다.

    전역 작업 건강

    문서 작업의 ‘확인 필요’는 현재 데이터 호환성과 다른 판정입니다. 작업 손상, 템플릿 없음, 지원하지 않는 작업 방식, 확인된 Template·Binding drift, 끊어진 기본 데이터 참조만 포함합니다.

    구현하지 않는 것

    새 홈 화면, 내비게이션 건강 배지, 실제 즐겨찾기·최근 사용 저장 API, 실제 클립보드 검증, 실제 템플릿 diff, 태그 축 group-by 전환, 문서 작업 삭제, 완전한 신규 작업 마법사, ERP 파일 이력, 데이터 카탈로그, 유사 스키마 자동 식별은 포함하지 않습니다.

    현재 변경을 먼저 정리하세요

    기본 규칙으로 저장할까요?

    원본 파일에서 수정

    현재 선택과 실행 문맥은 유지됩니다. 이 시안은 원본 파일을 직접 바꾸지 않습니다. 외부에서 ‘성명’ 열을 복구한 뒤 다시 분석해야 하며, 지금 상태를 준비 완료로 바꾸지 않습니다.

    이 템플릿으로 새 문서 작업 만들기

    새 identity를 만든 뒤 현재 레코드 선택을 유지하고 검증합니다. 출발점 작업의 Binding은 변경하지 않습니다.

    기본 규칙으로 저장

    이번 세션에서 바꾼 항목만 새 Binding revision에 저장합니다.

      그룹 이동

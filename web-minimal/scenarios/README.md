# 비교 시나리오

시안은 같은 상태에서 비교해야 한다. 이 디렉터리는 비교 상태의 식별자와 설명을 고정한다.

현재 `blank`만 실제 기준점이며, `normal`과 `missing-values`는 배관 연결 단계에서 동일한
테스트 자료와 격리 앱 홈을 갖도록 채울 예약 시나리오다. `fixture: null`인 상태에서는
제품 데이터가 준비됐다고 간주하지 않는다.

실행기는 `-Scenario` 값에 대응하는 JSON이 있는지 확인하고 시안·시나리오 조합별로
`.ui-lab-home/<variant>/<scenario>/`를 사용한다. 향후 시연 하네스가 fixture를 소비해도 이
격리 경계를 유지한다.
